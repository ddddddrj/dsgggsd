# ANGAR-07 · ALPHA vs DELTA

Шут-хаус в ангаре на three.js r166 + Bullet (ammo.js). Готовая карта — один файл
[`angar_map.html`](angar_map.html): открывается двойным щелчком, работает офлайн
(three.js, ammo.js и wasm вшиты внутрь).

Качество выбирается само, либо `?q=low|med|high|ultra`. Отладка: `?nocache`
(без кэша текстур и объёма света), `?fixedres` (без адаптивного разрешения),
`?avol=0` (без запечённого затенения — сравнить «до/после»), F3 — счётчики.

## Как устроена картинка

- **Свет**: солнце и рассеянный свет в соотношении ≈4:1. Рассеянный свет и
  отражения гасит запечённый при загрузке объём (две 3D-текстуры: затенение
  на 9 м с тёплым отскоком от OSB и контактное на 1.5 м). Считается ≈0.3 с и
  кэшируется в IndexedDB.
- **Цвет**: AgX → плёночная S-кривая, без подъёма чёрного; высотный туман с
  подсветкой со стороны солнца; адаптация глаза в доме.
- **Частицы** (огонь, дым, пыль, искры) рисуются отдельным проходом в половинном
  разрешении, мягко гаснут у стен и потолка; поверх — марево над огнём и
  ударная волна взрывов.
- **Отражения**: окружение снимается кубической камерой из ангара и
  переснимается при смене времени суток.

## Детали и разрушаемость

- **Двери** — филёнчатые крашеные полотна (пять цветов краски, износ, петли,
  наличники). У каждой двери своя карта повреждений (слой `DataArrayTexture`):
  пуля пробивает полотно насквозь — входное отверстие аккуратное, выходное
  рваное, с вырванными волокнами; в пробоины видно и светит солнце (тень тоже
  с дырами). Очередь выбивает филёнки — куски дерева падают на пол, обвязка
  держится дольше, стойка у петель не ломается никогда. С петель дверь не
  слетает ни от пуль, ни от гранаты; удар с разбега вырывает замок с куском дерева.
- **Вертолёт** — исправлен «просвечивающий» корпус (нормали лофта смотрели
  внутрь). Двойная обшивка с интерьером: кресла, приборная доска с подсветкой,
  десантные сиденья, открытая сдвижная дверь. Текстура обшивки: панели,
  заклёпки, лючки, трафареты, копоть выхлопа, подтёки масла, сколы краски;
  винты с профилем NACA, автомат перекоса, хвостовой редуктор, антенны, ПВД,
  фары, проблесковый маяк, стремянка техника, швартовка.
- **Дым** — общий слой под кровлей: тонкая пыльная дымка всегда, при пожаре
  копится, опускается и темнеет, ночью подсвечивается огнём снизу; столбы света
  в дыму ярче. Считается аналитически в шейдере тумана, поверх — редкие клубы.
- **Пол** — затирочные круги, вскрытый заполнитель, высолы, волосяные трещины;
  разметка проездов, штриховка у ворот, щелевые и круглые трапы, анкерные
  плиты, ремонтные заплаты, масло, следы шин.
- **Свет** — ночью над проходом к вертолётной площадке мерцает перегоревшая
  люминесцентная лампа (холодный белый, конус в пыли, искры из патрона);
  натриевые светильники светят тёплым, маяки вертолётов мигают красным.

Отладка из консоли: `ANGAR.shootFrom(x,y,z, lx,ly,lz)` — выстрел из любой
точки, `ANGAR.SMOKE.level` — задымление, `ANGAR.DEAD_LAMP` — лампа.

## Сборка

```sh
npm install
npm run build        # → angar_map.html
```

| файл | что внутри |
|---|---|
| `src/game.js` | весь код игры (ES-модуль) |
| `src/index.html` | разметка, стили, меню, HUD, сторож загрузки |
| `src/three-entry.js` | какие части three.js попадают в бандл |
| `vendor/ammo.wasm.js`, `vendor/ammo.wasm.wasm` | Bullet (zlib) |
| `build.mjs` | сборка через esbuild в один HTML |

## Управление (по умолчанию, меняется в «Настройках»)

WASD — движение, Shift — бег, Space — прыжок, C — присесть (Ctrl — только в
полноэкранном режиме с захватом клавиатуры), ЛКМ/ПКМ — огонь/прицел,
R — перезарядка, G/T — граната/зажигательная, E — дверь (с разбега — выбить),
F — пополнить боезапас у ящика на базе, V — полёт/ходьба, M — меню, Esc — пауза.
