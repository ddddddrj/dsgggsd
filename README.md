# ANGAR-07 · ALPHA vs DELTA

Шут-хаус в ангаре на three.js r166 + Bullet (ammo.js). Готовая карта — один файл
[`angar_map.html`](angar_map.html): открывается двойным щелчком, работает офлайн
(three.js, ammo.js и wasm вшиты внутрь).

Качество выбирается само, либо `?q=low|med|high|ultra`. Отладка: `?nocache`
(без кэша текстур и объёма света), `?fixedres` (без адаптивного разрешения),
`?avol=0` (без запечённого затенения — сравнить «до/после»), F3 — счётчики.

## Как устроена картинка

- **Свет**: солнце и рассеянный свет в соотношении ≈4:1. Рассеянный свет и
  отражения гасит запечённый при загрузке объём (две 3D-текстуры: затенение
  на 9 м с тёплым отскоком от OSB и контактное на 1.5 м). Считается ≈0.3 с и
  кэшируется в IndexedDB.
- **Цвет**: AgX → плёночная S-кривая, без подъёма чёрного; высотный туман с
  подсветкой со стороны солнца; адаптация глаза в доме.
- **Частицы** (огонь, дым, пыль, искры) рисуются отдельным проходом в половинном
  разрешении, мягко гаснут у стен и потолка; поверх — марево над огнём и
  ударная волна взрывов.
- **Отражения**: окружение снимается кубической камерой из ангара и
  переснимается при смене времени суток.

## Сборка

```sh
npm install
npm run build        # → angar_map.html
```

| файл | что внутри |
|---|---|
| `src/game.js` | весь код игры (ES-модуль) |
| `src/index.html` | разметка, стили, меню, HUD, сторож загрузки |
| `src/three-entry.js` | какие части three.js попадают в бандл |
| `vendor/ammo.wasm.js`, `vendor/ammo.wasm.wasm` | Bullet (zlib) |
| `build.mjs` | сборка через esbuild в один HTML |

## Управление (по умолчанию, меняется в «Настройках»)

WASD — движение, Shift — бег, Space — прыжок, C — присесть (Ctrl — только в
полноэкранном режиме с захватом клавиатуры), ЛКМ/ПКМ — огонь/прицел,
R — перезарядка, G/T — граната/зажигательная, E — дверь (с разбега — выбить),
F — пополнить боезапас у ящика на базе, V — полёт/ходьба, M — меню, Esc — пауза.
